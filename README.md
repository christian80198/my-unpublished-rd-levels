# my unpublished rhythm doctor levels
uhhh it's pretty much self explanatory. you can download my rhythm doctor levels here and play them if you have the game on steam

# what is this for?
i made this repo specifically for the levels that i made but can't be published on the workshop due to the artists not being on the verified artist list for rd and adofai.
you can find this page either on my github or my straw.page

# why github?
why not? it's cooler than google drive imo

# where can i find the levels?
i'll have them either sorted out by artist or just in a folder. depends on what i feel like doing.

# how do i import them into rhythm doctor?
just download the .rdzip and put it somewhere like your downloads (personally i keep them in a separate folder in my documents folder). then, if you have rhythm doctor, do the following:
custom levels -> import level -> browse...
then find the level and import it. you can also import multiple at once
